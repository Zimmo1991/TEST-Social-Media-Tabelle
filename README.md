# TEST-Social-Media-Tabelle

Eine einfache, lokal nutzbare Web-App zur Vorbereitung eines Social-Media-Beitrags.

## Funktionen

- Bild oder Video per Drag-and-drop oder Dateiauswahl hinzufügen
- Direkte Vorschau und Möglichkeit zum Entfernen
- Frei editierbarer Beitragstext mit Zeichenzähler
- Responsive Darstellung für Desktop und Mobilgeräte

Die Dateien werden nur lokal im Browser angezeigt und nicht hochgeladen oder gespeichert.

## Lokal starten

Es sind keine Abhängigkeiten und kein Build-Schritt erforderlich.

1. Im Projektordner einen lokalen Webserver starten:

   ```bash
   python -m http.server 8000
   ```

2. [http://localhost:8000](http://localhost:8000) im Browser öffnen.

Alternativ kann `index.html` direkt im Browser geöffnet werden.
